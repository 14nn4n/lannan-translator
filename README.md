# مُترجم PDF

موقع ثابت باللغة العربية لترجمة النصوص المستخرجة من ملفات PDF.

## الاستخدام
افتح الموقع، ارفع ملف PDF، اختر لغة المصدر والهدف، ثم اضغط "ترجمة الملف".

## النشر
يُنشر تلقائياً على GitHub Pages عند كل تحديث لفرع `main` عبر GitHub Actions.

## حدود النسخة التجريبية
- يعمل مع ملفات PDF التي تحتوي على نص قابل للاستخراج.
- لا يتضمن OCR للصفحات الممسوحة ضوئياً.
- يعيد إنشاء ملف PDF نصي، ولا يحافظ حالياً على الصور والجداول أو التصميم الأصلي.
- الترجمة تعتمد على خدمة MyMemory الخارجية، وقد تخضع لحدود الاستخدام وسياسة الخصوصية الخاصة بها.
- دعم تشكيل الحروف العربية في PDF الناتج محدود في هذه النسخة.

لا ترفع مستندات حساسة أو سرية إلى هذه النسخة التجريبية.
